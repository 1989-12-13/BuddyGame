## 启动本地开发环境（晚间）

- `npm run dev`（scripts/dev.mjs）会同时起 tts-server(8787) + vite(5173)，任一个退出会连带 kill 另一个。
- 8787 常被上次会话遗留的 tts-server 进程占着 → dev.mjs 直接 EADDRINUSE 崩掉，两个服务都起不来。
  **解决办法**：先 `netstat -ano | grep :8787` 判断，若已有一个实例在跑，就只单独起 vite：
  `node node_modules/vite/bin/vite.js`（后台运行）。
- 无 `.env.local` / VOLCANO_TTS_KEY 时，tts-server 只打印警告，语音不可用但游戏可正常玩（字幕独立）。
- 打开地址：http://localhost:5173
