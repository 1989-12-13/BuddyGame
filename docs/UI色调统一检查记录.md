# UI 色调统一与节点检查

日期：2026-09-09。针对任务卡“详细记录”与急救排序小游戏的截图反馈。

## 色彩与组件规则

| 用途 | 浅色模式 | 深色模式 |
|---|---|---|
| 页面底色 | `#e9eeeb` | `#101c23` |
| 面板 | `#fcfcf7` | `#18272f` |
| 主要文字 | `#223c37` | `#f0eee7` |
| 辅助文字 | `#526961` | `#b3c1c3` |
| 操作与完成提示 | `#247b65` | `#8bd4bc` |
| 待确认提示 | `#865d21` | `#e7bd82` |
| 危险提示 | `#a64842` | `#efa69c` |

工作台内的旧颜色变量接入统一色板。未选中的状态、判定码和子编码采用中性背景；选中后显示淡色背景与描边，意识／呼吸按钮额外显示勾选标记。危险选项只在选中时突出。

指导标题使用正文色，外框使用普通分隔线。小游戏移除亮蓝标题与阴影，使用统一圆角、线框和 Lucide 图标。按压操作使用青绿色及轻微缩放反馈，移除红色发光。普通体征说明保持辅助文字色，低余量的状态文字与进度条保留危险色。浅色任务侧栏的阴影同步减弱。

## 节点检查

1. 任务卡：类型检查通过；状态按钮保留原操作回调，增加 `aria-pressed`。
2. 指导与小游戏：相关 7 项交互测试通过，覆盖排序撤销与提交、人工呼吸暂停、两轮 CPR 和派车入口。此次不调整游戏计时、医学指令或评分规则。
3. 浅深色浏览器检查：两项通过。实际渲染的选中／未选中状态按钮及结束通话文字，对比度均至少为 4.5:1；检查键盘焦点、1024px 任务侧栏与 390px 手机布局。
