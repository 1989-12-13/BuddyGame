# 《120 调度台》投稿交付清单

更新日期：2026 年 9 月 7 日

## 当前可交付版本

当前 Demo 已完成五通固定主线：老人跌倒、胸痛、外伤出血、脑卒中疑似、心脏骤停。核心循环为“接听来电 → 确认地点与患者情况 → 判断响应优先级 → 逐节点规划路线 → 派车 → 电话指导 → 现场交接 → 行动复盘”。场景练习和随机班次作为重玩入口保留。

UI 采用温暖写实的深蓝灰调度台。1280px 及以上为通话、工作区、任务卡三栏；960–1279px 的任务卡按需展开；更窄屏幕使用通话、工作区、任务卡三个标签页。正文以 16px 为基准，辅助文字不低于 14px，主要点击区域不小于 44px。青绿色表示可执行操作，琥珀色表示待确认，红色只用于危险与有后果的操作。

封面城市夜景、调度工作台与离线地图均为项目内原创 SVG。在线底图使用 CARTO/OSM 数据并在地图控件中保留署名；界面图标来自 Lucide。提交前将依赖许可证与素材来源一并导出到投稿包。

## 已完成的关键修复

| 范围 | 最终行为 |
|---|---|
| 统一暂停 | 手动暂停、设置、帮助、确认框和后台切换冻结世界、车辆、动作计时、小游戏与音频；关闭嵌套弹窗不会提前恢复 |
| 有效游玩时间 | 问询改为同一世界时钟上的动作持续时间，不再直接额外增加班次秒数 |
| 指导提交 | 校验来电实例、当前步骤、合法选项和 0–1 有限分数；重复或过期结果不结算 |
| 定时事件 | 采用阈值跨越触发并按事件 ID 去重；问询事件使用明确问题 ID |
| 派车条件 | UI 与 reducer 共用同一校验结果，逐项说明地址、意识、呼吸、分诊、路线或车辆状态 |
| 音频与字幕 | 默认整句字幕；上一句可重播或停止；TTS 超时、失败和旧来电延迟返回均不阻断下一步 |
| 地图降级 | 在线底图失败后显示本地示意图，地点、车辆与路线操作仍可完成 |
| 结算语义 | 操作评价与患者结局分开；复盘只引用实际发生的问询、派车、指导和事件 |
| 检查点 | 仅保存已完成通话；刷新或退出后从当前来电开头重试，存储不可用时仍能游玩 |
| 边界输入 | 快速连点、陈旧来电实例、非法步骤、重复派车、重复评分与无车派遣均被执行层拒绝 |

## 演示视频建议镜头
