# 《120 调度台》投稿汇报 · 设计定调说明

单文件网页汇报稿：`slides/index.html`（双击即用，无构建、无外部运行时依赖）。

---

## 1. 定调说明 Design Direction Note

| 项 | 决策 |
|---|---|
| **目的** | 一次 15 分钟内的投稿汇报 / 答辩：讲清这个公益急救调度模拟游戏做的是什么、为什么这样设计、工程上做到什么程度、边界在哪。 |
| **受众** | 评审。关注点依次是：真实问题是否存在 → 设计是否有依据 → 完成度与质量证据 → 合规与诚实度。 |
| **调性 Tone** | **工业实用 / 调度台（Industrial · utilitarian）**。仪表盘式的页眉 HUD、等宽数字、发丝边框、信息密度可控。与产品「写实 DOC / 应急指挥中心」的视觉同源，不另起一套风格。**全稿只走这一个方向，不混搭。** |
| **主题选择** | 采用项目自带的 **light（日间调度台）** 令牌，而非默认的深色主题。理由：投影与打印可读性优先，浅底在会议室光照下更稳；同时它是产品真实存在的主题之一，不是为 PPT 临时编的配色。 |
| **字体** | 中文 **Noto Sans SC**（思源黑体，400/500/700/900）；数字与代号 **JetBrains Mono** —— 直接沿用产品 `--font-mono`，让汇报与产品同源；英文小标 **Barlow Condensed**（压缩字形，控制室标识感）。避开 Inter / Roboto / Arial / system-ui 等默认字体。 |
| **配色** | 主色 **青绿 `#247b65`**（可执行），辅助 **琥珀 `#9a6a1e`**（待确认）、**红 `#b0413a`**（危险 / 有后果）；60 / 30 / 10 分配：浅灰绿底 60%、纸面与文字 30%、青绿强调 10%。**单屏只有一个强调色。** |
| **记忆点** | 每页页眉是一条**调度台 HUD**（章节号 + 状态 chip），页脚左侧是**口播提示**，右侧是 `03 / 16` 等宽页码；整份稿子像一块值班面板，而不是一份模板文档。 |
| **克制的边界** | 有渲染但不花哨：发丝网格 + 纸感颗粒 + 四角括号 + 两张手写 SVG（路网、热度曲线）+ 入场错峰。没有渐变爆炸、没有 3D、没有自动播放。 |

## 3. 动效规格 Motion Spec

| 类型 | 做法 | 时长 / 缓动 |
|---|---|---|
| 入场序列 | 每页元素按 `--d: 0…6` 错峰：页眉 → 标题 → 导语 → 主体块 → 结论块 | 组间隔 **90ms**，单组 640ms / `--ease-out` |
| 翻页 | 非当前页 `translateX(±24px) + opacity`，只动 transform 与 opacity | 320ms / `cubic-bezier(0.4,0,0.2,1)` |
| 数据条 | 进场时宽度从 0 补到目标值（`data-w`） | 640ms / `--ease-out` |
| 响铃脉冲 | 仅线路墙的响铃图标 | 1.6s 循环 |
| 路线流动 | 路网 SVG 的 `stroke-dashoffset` | 1.4s 线性 |
| 悬停 | 按钮换强调色 + 底色，不只是变亮 | 150ms / ease-out |
| 降级 | `prefers-reduced-motion: reduce` 下**全部关闭**（入场、翻页、脉冲、流动、数据条） | — |

布局兜底：若某页内容超过可视高度（换字体、改文案都可能触发），脚本会按 `clientHeight / scrollHeight` 等比缩放该页主体（下限 0.86），保证**永不裁切**。

### 工程自检

- 标签配对：section 16/16、div 240/240、table 13/13、svg 7/7 —— 全部闭合。
- 脚本：`node --check` 通过，无外部 JS 依赖。
- 舞台：固定 1280×720 画布等比缩放，任意窗口尺寸不溢出；`#s1…#s16` 支持深链与刷新续播。

- 字体：Google Fonts 加载失败时回落到思源黑体 / 系统等宽字形，版式不塌。

## 5. 使用与改稿

| 操作 | 按键 |
|---|---|
| 翻页 | `→` / `←`、`空格`、`PageDown` / `PageUp`；点击页面也可翻到下一页 |
| 首 / 尾页 | `Home` / `End` |
| 全屏 | `F` |
| 打印 / 导出 PDF | `P`（浏览器打印对话框选「另存为 PDF」，横向） |

改稿约定：

1. **只改内容，不改版式**：每页结构是 `header.s-head` + `div.s-body` + `footer.s-foot`，改文字不会破坏对齐。
2. **入场序号** `--d:0…6` 决定元素出现顺序，新增块时按顺序给号即可。
3. **数字一律用等宽**：把数字包在 `class="num"` 或放进 `.mono`，保持 `tabular-nums` 竖向对齐。
4. **别写死颜色**：改色请改 `:root` 里的令牌，与产品 `tokens.css` 保持一致。
5. **页脚口播提示**是给汇报人自己看的，投影时如需隐藏，删掉对应 `.cue` 文本即可（页脚与页码不会错位）。
